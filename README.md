# NHS A&E Performance Analysis (England)

## Overview
This project analyses national NHS England Type 1 Accident & Emergency (A&E) performance using monthly data from April 2023 to March 2025.

The analysis focuses on demand trends, four-hour breaches, and performance against the NHS 95% standard, with particular attention to winter pressure impacts.

## Objectives
- Analyse trends in Type 1 A&E attendances
- Quantify attendances breaching the four-hour standard
- Assess performance against the 95% NHS target
- Identify seasonal (winter) pressure effects
- Present insights through an executive-level dashboard

## Tools Used

## Key Insights
- Type 1 A&E attendances remain consistently high, with clear winter peaks
- Four-hour breaches increase significantly during winter months
- Performance remains persistently below the 95% NHS standard
- Rolling averages indicate structural pressure rather than short-term volatility

## Methodology
- Data reshaped into long format for flexible aggregation
- Custom measures created for attendance, breaches and performance
- RAG thresholds aligned to NHS standards
- Seasonal context added through winter period flagging and annotations
